# ✈️ Airline Flight Price & Performance Dashboard | Power BI

An interactive Airline Flight Price & Performance Dashboard developed using Microsoft Power BI and Excel to analyze airline pricing, flight routes, travel class, stops, duration, arrival/departure time and booking lead time.

---

## 🎯 Project Objective

Airline ticket prices vary depending on multiple factors such as airline, route, class, stops, duration and days remaining before departure.

The objective of this project is to transform raw airline data into an interactive dashboard that helps analyze:

- Airline pricing
- Flight availability
- Source and destination cities
- Travel class
- Number of stops
- Flight duration
- Arrival and departure times
- Booking lead time
- Cheapest and highest-priced flights

## 🔍 Key Insights

### ✈️ Airline Distribution

Vistara has the largest number of flight records, followed by Air India and Indigo.

### 💰 Maximum Price

Vistara has the highest maximum ticket price in the dataset at approximately ₹123K.

### 🏷️ Class

Economy represents approximately 69% of flight records, while Business represents approximately 31%.

### 🛑 Stops

One-stop flights dominate the dataset at approximately 84%.

### 🌙 Arrival Time

Night is the most common arrival period.

### 🏙️ Source Cities

Delhi and Mumbai have the highest number of flight records among the analyzed cities.

### 💸 Cheapest Flight

The minimum ticket price in the dataset is ₹1,105.
